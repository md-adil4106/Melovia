# Architectural Decision Records (ADRs)

This directory records all major architectural decisions made in the AMDE project.

## ADR Template

Each record should follow this structure:

```markdown
# ADR [Number]: [Title]

## Status
[Proposed | Accepted | Superseded | Deprecated]

## Context
What was the problem or motivation? What options were considered?

## Decision
What was decided and why?

## Consequences
What are the trade-offs, advantages, and risks of this decision?
```
